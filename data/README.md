# 데이터 설명

## 1. 파일

| 경로 | 내용 | 출처 |
|---|---|---|
| `sample/electricity_daily.csv` | 센터 교육동 **일별 전력 사용량 시뮬레이션** 2024-10-01 ~ 2026-09-30 (730행) | `make_sample.py`로 생성 (아래 규칙, seed 260000) |
| `real/` | 실데이터 (확보 시) | `real/source.md`에 출처·라이선스 기록 |

분석 파이프라인은 `python src/run.py --source sample` 또는 `--source real`로 둘 다 처리한다. 실데이터 컬럼 이름이 달라도 `src/load.py`가 날짜·값 컬럼을 키워드로 찾는다.

## 2. 컬럼 (sample)

| 컬럼 | 형식 | 설명 |
|---|---|---|
| `date` | YYYY-MM-DD | 일자 |
| `value` | float | 일 전력 사용량 (kWh) |
| `temp_c` | float | 일평균 기온 (℃), 기온 모델로 생성 |
| `is_holiday` | 0/1 | 공휴일 여부 |
| `memo` | 문자열 | 학기/방학, 주말, 공휴일 이름, 이상치 표시 |

## 3. 시뮬레이션 생성 규칙 (`make_sample.py` RULES와 동일)

이 데이터는 **가상 데이터**다. 실제 센터 건물의 측정값이 아니며, 분석 방법을 검증하고 리포트 구조를 완성하기 위해 만들었다. 리포트에서 수치를 인용할 때는 "시뮬레이션 데이터 기준"임을 명시한다.

| 요소 | 규칙 | 의도 |
|---|---|---|
| 기본값 | 1,800 kWh/일 | 중소형 교육동 가정 |
| 학기 / 방학 | 3~6월·9~12월 ×1.25 / 1~2월·7~8월 ×0.80 | 수업·실습이 있는 학기에 사용량 증가 |
| 주말 | 토·일 ×0.55 | 건물 상주 인원 감소 |
| 공휴일 | ×0.50 (고정 목록, 설·추석은 해당 연도 날짜) | 주말보다 조금 더 낮음 |
| 기온 | 연중 사인 곡선(평균 13.5℃, 진폭 13℃, 7월 말 최고) + 노이즈 ±3℃ | 창원 기후 대략 반영 |
| 냉난방 | 26℃ 초과·5℃ 미만 구간에서 1℃당 +1.5% | 여름·겨울 피크 |
| 추세 | 연 +3% | 장비 증설 가정 |
| 노이즈 | 정규분포, 표준편차 4% | 일상적 변동 |
| 이상치 | 평일 6일: 정전·점검 ×0.35 (3일), 대형 행사 ×1.60 (3일) | 이상치 탐지 검증용, memo에 표시 |

재생성: `python make_sample.py` (같은 시드면 같은 파일). 규칙을 바꾸면 이 표도 같이 고친다.

## 4. 실데이터로 교체하는 방법

1. CSV를 `real/`에 넣고 `real/source.md`에 출처(URL·제공기관·데이터셋명), 기간, 단위, 라이선스(공공누리 유형), 다운로드 일시를 적는다.
2. `python src/run.py --source real --date-col <날짜 컬럼> --value-col <값 컬럼>` (컬럼을 지정하지 않으면 자동 탐색).
3. 기온 컬럼이 없으면 기온 관련 분석(Q3 상관)은 자동으로 건너뛴다.
4. `REPORT.md` 3장의 데이터 설명과 수치를 `output/summary.txt`로 다시 채운다.

## 5. 라이선스 주의

- 시뮬레이션 데이터: 이 저장소 안에서 자유롭게 사용.
- 실데이터: 제공기관의 이용 조건(공공누리 제1~4유형)을 `source.md`에 적고, 출처 표시 조건을 지킨다. 재배포가 제한된 데이터는 저장소에 넣지 않고 수집 방법만 문서화한다.
