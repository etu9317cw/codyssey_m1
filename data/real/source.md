## 3. 사용자가 직접(또는 브라우저 클릭으로) 받으면 좋은 후보 2개

1. **EPSIS 전력통계정보시스템 — 전력수급실적(월별, 2002~현재)**
   - URL: https://epsis.kpx.or.kr/epsisnew/selectEkmaUpsBftChart.do?menuId=030100
   - 절차: 로그인 없음. 조회 기간을 2002-01~최근으로 설정 → 조회 → 우측 상단 "EXCEL" 또는 "CSV" 버튼 클릭. 월별 전력수요(발전량·판매량 등) 280개월 이상.
   - 추천 이유: 로그인 불필요, 월별 100포인트 이상, 전국 단위 공식 통계.
2. **공공데이터포털 — 한국전력공사_시군구별 전력판매량 정보 (XLSX, 월별·시군구·계약종별)**
   - URL: https://www.data.go.kr/data/15069677/fileData.do
   - 절차: 페이지의 "다운로드" 버튼 클릭(JS). 로그인 요구 시 공공데이터포털 회원가입 후 재시도. 창원시(의창·성산·마산합포·마산회원·진해구) 계약종별 월별 판매량 추출 가능. 기간은 파일 열어 확인 필요(데이터셋명 기준 2024-05까지).
   - 대안: 한국전력 전력데이터 개방포털(bigdata.kepco.co.kr) 회원가입 → "지역별 계약종별 전력사용량" 월별 데이터 다운로드(경남 창원, 2013~).
